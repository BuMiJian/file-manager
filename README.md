# file-manager

按编码规则给调研收集的资料、讲义、视频统一编号重命名，并把编号写入 SQLite 台账（`data.db`）。

## 编码规则

| 类型 | 格式 | 例子 |
|---|---|---|
| 收集资料 | `ZL{YYMMDD}-{序号}-文件名` | `ZL251230-0001-油田生产运行管理实施细则.pdf` |
| 讲义 | `JY{序号}-{资料编码}-文件名` | `JY0001-ZL251230-0001-BaobabFPF火炬操作规程.pdf` |
| 视频 | `SP{序号}-{资料编码}-文件名` | `SP0001-ZL251230-0001-生产分离器工作原理.mp4` |
| 三维文件 | `SW{序号}-{资料编码}-文件名` | 暂未实现 |
| 题 | `T{序号}-{讲义/视频/三维编码}` | 暂未实现 |

- 资料的日期取自文件所在目录往上最近一个以 `YYMMDD-` 开头的目录名，按 20YY 年解析；序号在同一日期内递增。
- 讲义、视频的序号在同类型内全局递增，接着台账中已有的最大序号往下编。
- 讲义和资料是多对一关系：一份资料可以对应多份讲义。

## 用法

只依赖 Python 标准库，无需安装依赖。

```bash
# 收集资料（不传目录时使用 src/material.py 中的 DEFAULT_FOLDER）
python3 src/material.py [资料目录]

# 讲义和视频
python3 src/handout.py <讲义目录> --map 对应表.xlsx
```

运行结束会列出跳过的文件及原因，并输出重命名、已有编号、跳过的数量。

### 讲义对应表

`handout.py` 读取 xlsx 的第一个工作表，第一行为表头，需要有“资料”和“讲义”两列（列顺序不限）：

- **资料**：填资料编码 `ZL251230-0001`，或完整的资料文件名，程序会从中提取编码。
- **讲义**：填讲义的原始文件名，带不带后缀都可以。

后缀为 `.mp4`、`.mov`、`.avi`、`.mkv`、`.wmv` 的文件按视频（SP）编号，其余按讲义（JY）编号。对应表中找不到、或对应的资料不在台账中的文件会被跳过。

## 处理逻辑

1. 递归扫描目录下的文件，跳过隐藏路径、符号链接、`.db` 文件和 Office 临时文件（`~$` 开头）。
2. 先把已经符合命名规则的文件登记到台账，避免新文件占用旧编号；编号和台账不一致时报错退出。
3. 再给未编号的文件生成新名称、写入台账并重命名。
4. 中途出错时，数据库回滚，已重命名的文件也会改回原名。

## 文件说明

| 文件 | 说明 |
|---|---|
| `src/material.py` | 收集资料重命名（ZL） |
| `src/handout.py` | 讲义、视频重命名（JY、SP） |
| `src/question.py` | 题库编号（T），尚未实现 |
| `src/common.py` | 共用的台账路径、建表、日期校验和 xlsx 读取 |
| `src/revoke.py` | 早期的撤销脚本，与当前命名规则不匹配，暂不建议使用 |
| `data.db` | 台账数据库，固定在项目根目录，不纳入 git |
| `web/` | 可视化页面（预留，尚未实现） |

## 注意事项

- 程序会直接重命名真实文件，首次对新目录运行前建议先备份。
- 讲义台账里的路径是相对于讲义目录记录的，请每次使用同一个讲义目录。
- 设置环境变量 `FILE_MANAGER_DB` 可以改用其他台账文件，便于测试。
